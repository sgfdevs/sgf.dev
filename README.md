# Springfield Devs website

This repository is for the public [sgf.dev](https://sgf.dev) frontend.
The Umbraco CMS and backend live in [cms.sgf.dev](https://github.com/sgfdevs/cms.sgf.dev).

The legacy .NET application, Razor templates, uSync files, styles, and build and
release automation have been removed from this repository. They remain in the
CMS repository and Git history. No replacement frontend is included yet.
